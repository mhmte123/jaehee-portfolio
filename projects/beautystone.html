Overview

프로젝트 소개

뷰티스톤의원은 서울 합정에 있는 피부과로, 리프팅 시술을 중심으로 국내외 환자를 진료합니다. 기존 홈페이지는 Framer로 만들어져 있어 프로모션 항목이나 가격을 바꾸려면 매번 이미지를 다시 제작해야 했고, 외국인 환자를 위한 언어 대응과 사이트 안에서 상담·예약으로 이어지는 흐름이 부족했습니다.

이 프로젝트에서 저는 기획, UX/UI 디자인, 프론트엔드 개발을 전담했고 백엔드 담당자 1인과 결제 영역을 협업했습니다. 브랜드 무드보드를 먼저 세워 디자인 기준을 잡고, 그 기준을 디자인 토큰과 공용 컴포넌트로 옮겨 41개 페이지를 일관되게 만들었습니다. 4주 만에 실 도메인으로 전환해 현재 실제 방문자를 받고 있습니다. 운영 사이트는 이후 병원 측에서 계속 바뀌므로, 제가 작업을 마친 2026년 8월 시점의 화면을 그대로 굳힌 아카이브를 따로 두었습니다. 아래 버튼과 화면 캡처는 그 아카이브로 연결됩니다.

Problem

발견한 문제점

UX 문제

프로모션이 정적 이미지 한 장으로만 제공되어 시술 선택에서 상담·예약으로 이어지는 경로가 없음
대만·일본·태국·중국권 환자 유입이 있는데 언어별 안내와 상담 채널이 갖춰지지 않음
시술 정보가 장비 이름 위주로 나열되어 방문자가 자기 고민과 연결하기 어려움

UI · 운영 문제

브랜드 톤의 기준 문서가 없어 페이지마다 색·서체·간격이 제각각
콘텐츠 갱신을 디자인 툴에 의존해 병원 담당자가 직접 수정할 수 없음
구조화 데이터, 언어별 대체 주소, 공유 이미지 같은 검색·공유 기반이 없음

Solution

해결 방법

브랜드 무드보드(컨셉·로고·컬러·타이포·모션 8개 보드)를 먼저 세우고, 이를 디자인 토큰 단일 출처와 공용 UI 컴포넌트로 옮겨 전 페이지에 적용
프로모션을 DB 기반으로 전환해 장바구니 → 일정 선택 → 예약 접수 → 비회원 조회까지 사이트 안에서 완결되는 흐름 설계
한국어를 기준 스키마로 두는 6개 언어(ko·en·ja·th·zh·tw) 체계 구축. 언어 선택 대문, 언어별 상담 채널(카카오·LINE·WhatsApp·위챗) 분기
어드민 백오피스 8종(프로모션·예약·상담·회원·공지·게시판·전후사진) 제작으로 병원 담당자가 코드 수정 없이 콘텐츠 편집
시술 랜딩 15개 섹션 기획·구현: 풀페이지 스크롤, 배경 영상, WebGL 물결, 부위별 인터랙션, 모바일 전면 재설계
구조화 데이터, hreflang·canonical, OG 이미지, robots 정비로 검색·공유 기반 마련. 의료광고 규정을 고려해 완곡 표현 유지, 별점 스키마와 근거 없는 '최초' 표현은 제외
터치 기기의 hover·click 충돌, CSS 특정도 역전, 이미지 캐시 같은 실무 이슈를 재현·정리해 팀 문서(HANDOFF·DESIGN)로 남김
AI 코딩 도구(Claude Code)를 활용해 반복 마크업, 번역 데이터 정리, 리팩토링 속도 향상

Back Office

운영 도구 · 어드민 백오피스

병원 담당자가 개발자 없이 프로모션·예약·상담·공지·전후사진을 직접 운영할 수 있도록, 공개 사이트와 같은 디자인 체계 위에 관리 화면 8종을 만들었습니다. 편집 항목은 "코드 수정 없이 병원 담당자가 바꿔야 하는 것"을 기준으로 정했고, 관리자 인가는 화면이 아니라 DB 보안 규칙(RLS)에 두어 화면을 우회해도 데이터에 닿지 못하게 했습니다.

※ 개인정보(이름·연락처·이메일·주문번호)는 흐리게 처리했습니다. 캡처의 데이터는 대부분 개발 중 입력한 테스트 값입니다.
